# Worldwide

A travel photo map for Windows and Android. Mark visited countries, add photos, and sync between devices.

```sh
npm ci
npm run build
npm start
```

Open http://127.0.0.1:3000.

[Windows setup](desktop/README.md) · [Android setup](mobile/android/README.md)

Map data: [Natural Earth](https://www.naturalearthdata.com/).
