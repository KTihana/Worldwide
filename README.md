# Worldwide

A travel photo map for Windows and Android. Mark visited countries, add photos, and sync between devices.

[![Download for Windows](https://img.shields.io/badge/Download-Windows-4d6d5d?style=for-the-badge)](https://github.com/KTihana/Worldwide/releases/latest/download/Worldwide-Windows-Setup.exe)
[![Download for Android](https://img.shields.io/badge/Download-Android-4d6d5d?style=for-the-badge)](https://github.com/KTihana/Worldwide/releases/latest/download/Worldwide-Android.apk)

```sh
npm ci
npm run build
npm start
```

Open http://127.0.0.1:3000.

[Windows setup](desktop/README.md) · [Android setup](mobile/android/README.md)

Map data: [Natural Earth](https://www.naturalearthdata.com/).
